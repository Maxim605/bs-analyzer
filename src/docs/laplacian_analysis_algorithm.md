# Алгоритм анализа матрицы Лапласа по спектральным характеристикам

## Обзор

Алгоритм выполняет полный спектральный анализ матрицы Лапласа графа для определения его структурных свойств, оценки связности, выявления кластерной структуры и рекомендаций по количеству кластеров.

## Входные данные

- **Матрица Лапласа** (L) в формате Excel (xlsx)
- **Параметры анализа** (задаваемые вручную):
  - `zero_tol` — допустимая погрешность для определения нуля (по умолчанию: 1e-8)
  - `T_low_abs` — абсолютный порог низкой частоты (по умолчанию: 2.0)
  - `alpha` — коэффициент для относительного порога (по умолчанию: 0.02)
  - `gap_factor` — множитель для определения значимого eigengap (по умолчанию: 3.0)
  - `gap_ratio` — соотношение для значимости eigengap (по умолчанию: 1.5)
  - `frac_many_thresh` — порог доли малых λ для оценки "много" (по умолчанию: 0.2)
  - `k_search_fraction` — доля спектра для поиска eigengaps (по умолчанию: 0.5)
  - `max_k_search` — максимальное количество eigengaps для поиска (по умолчанию: 50)

## Этапы алгоритма

### 1. Предобработка матрицы

1. **Проверка квадратности**: матрица должна быть квадратной (N×N)
2. **Проверка числовых значений**: все элементы должны быть числовыми (без NaN/Inf)
3. **Проверка симметричности**: если матрица не симметрична, выполняется симметризация: `L = (L + L.T) / 2`
4. **Валидация структуры**: проверка, что матрица соответствует стандартному лапласиану

### 2. Вычисление спектра

Используется `np.linalg.eigh(L)` для вычисления:
- **Собственные числа** (eigenvalues): λ₁ ≤ λ₂ ≤ ... ≤ λ_N
- **Собственные векторы** (eigenvectors): v₁, v₂, ..., v_N

Собственные числа автоматически отсортированы по возрастанию.

### 3. Вычисление базовых констант

#### 3.1. Основные характеристики

- **N** — число вершин (размер матрицы)
- **λ_max** = max_i λ_i — максимальное собственное число
- **λ_min** = min_i λ_i — минимальное собственное число (обычно ≈ 0)
- **λ₂** — второе собственное число (Fiedler, алгебраическая связность)
- **n_zero** — количество собственных чисел, численно равных нулю (|λ_i| ≤ zero_tol)

#### 3.2. Eigengaps (разности собственных чисел)

Вычисляются разности между соседними собственными числами:
```
g_i = λ_{i+1} - λ_i
```

Для каждого gap определяется значимость:
- **По фактору**: `g_i > gap_factor * median(gaps)`
- **По абсолютному значению**: `g_i > alpha * λ_max`
- **По соотношению**: `g_i / mean_neighbor_gaps > gap_ratio`

#### 3.3. Статистики степеней вершин

Из диагонали матрицы Лапласа (которая содержит степени вершин):
- **d_max** — максимальная степень
- **d_avg** — средняя степень
- **d_min** — минимальная степень

#### 3.4. Пороги низких частот

Вычисляются два порога:
- **T_low_rel** = α * λ_max (относительный порог)
- **T_low_used** = max(min(T_low_abs, T_low_rel), small_eps) (используемый порог)

### 4. Оценка связности графа

#### 4.1. Количество компонент связности

- **n_components** = n_zero (количество нулевых собственных чисел)
- **is_connected** = (n_zero == 1)

#### 4.2. Интерпретация λ₂ (алгебраическая связность)

- **λ₂ < 1e-6**: очень малое значение → граф почти разделён
- **λ₂ < alpha * λ_max**: малое относительно λ_max → есть слабое место
- **λ₂ < 0.1 * λ_max**: умеренное → выраженная кластерная структура
- **λ₂ ≥ 0.1 * λ_max**: большое → граф хорошо связан

#### 4.3. Рекомендации по связности

- Если `n_zero > 1`: анализировать каждую компоненту отдельно
- Если `λ₂ < 1e-6`: проверить наличие узких мест (bottlenecks)

### 5. Оценка низкочастотной части спектра

#### 5.1. Вычисление доли малых собственных чисел

- **n_low** = количество собственных чисел ≤ T_low_used
- **fraction_low** = n_low / N

#### 5.2. Интерпретация

- **fraction_low ≤ 0.1** (few): мало низкочастотных мод → нет выраженной иерархической структуры
- **0.1 < fraction_low ≤ frac_many_thresh** (moderate): умеренное количество → возможна кластерная структура
- **frac_many_thresh < fraction_low ≤ 0.4** (many): много → выраженная иерархическая/кластерная структура
- **fraction_low > 0.4** (very_many): очень много → постепенная/плавная структура сообществ

### 6. Оценка локализации собственных векторов

#### 6.1. Inverse Participation Ratio (IPR)

Для каждого собственного вектора v вычисляется:
```
IPR(v) = Σ(v_i^4) / (Σ(v_i^2))²
```

**Интерпретация**:
- Большой IPR → вектор локализован (несколько вершин доминируют)
- Маленький IPR → вектор делокализован (равномерное распределение)

**Порог локализации**: `IPR > 1/√N`

#### 6.2. Оценка аномалий

Если первые несколько векторов (кроме первого, соответствующего λ=0) локализованы:
- Это указывает на локальные аномалии (изолированные вершины, листья)
- Рекомендуется пересмотреть выбор k или исключить аномальные вершины

### 7. Поиск кандидатов для количества кластеров (k)

#### 7.1. Анализ eigengaps

1. Фильтруются значимые gaps (по критериям из п. 3.2)
2. Сортируются по значению gap (убывание)
3. Для каждого значимого gap: **k = gap_index + 1**

#### 7.2. Определение уверенности

- **high**: `gap_ratio > gap_factor * 2` — очень значимый gap
- **medium**: `gap_ratio > gap_factor` — значимый gap
- **low**: иначе — умеренный gap

#### 7.3. Валидация кандидатов

- Если `k < n_zero`: уверенность снижается (k должно быть ≥ n_components)

### 8. Генерация рекомендаций

#### 8.1. Резюме анализа

Краткое описание:
- Размер графа (N)
- Количество компонент связности
- Оценка алгебраической связности
- Рекомендуемое k (если найдено)

#### 8.2. Список рекомендаций

Генерируются рекомендации на основе всех оценок:
- По связности (если граф несвязен)
- По низким частотам (если много низкочастотных мод)
- По локализации (если обнаружены аномалии)
- По выбору k (наиболее надёжные кандидаты)
- По валидации (рекомендация провести кластеризацию с несколькими k)

## Рекомендуемые значения параметров по умолчанию

- **zero_tol** = 1e-8 — для комбинаторного лапласиана обычно достаточно
- **T_low_abs** = 2.0 — удобный старт для комбинаторного L
- **alpha** = 0.02 — 2% от λ_max для относительного порога
- **gap_factor** = 3.0 — gap считается значимым, если в 3 раза больше медианного
- **gap_ratio** = 1.5 — минимальное соотношение для значимости
- **frac_many_thresh** = 0.2 — если >20% eigenvals ≤ T_low — "много"
- **k_search_fraction** = 0.5 — анализировать первые 50% спектра
- **max_k_search** = 50 — ограничение для больших графов

## Интерпретация результатов

### Связность

- **n_zero = 1**: граф связен, можно продолжать анализ
- **n_zero > 1**: граф несвязен, анализировать компоненты отдельно
- **λ₂ очень малое**: проверить наличие мостов/узких мест

### Кластерная структура

- **Много низкочастотных мод**: иерархическая структура → рассмотреть иерархическую кластеризацию
- **Умеренное количество**: возможна кластерная структура → спектральная кластеризация
- **Мало**: нет выраженной структуры → возможно, граф не имеет чётких сообществ

### Выбор k

- **Высокая уверенность**: использовать рекомендуемое k
- **Средняя/низкая уверенность**: провести валидацию с несколькими k, оценить качество кластеризации (silhouette, modularity, стабильность)

### Локализация

- **Есть аномалии**: проверить граф на изолированные вершины/листья
- **Сильная локализация**: спектральная кластеризация может быть нестабильной

## Дополнительные рекомендации

1. **Sensitivity analysis**: проверить устойчивость выводов при изменении порогов
2. **Валидация кластеризации**: для окончательного выбора k провести кластеризацию с несколькими значениями и оценить качество
3. **Визуализация**: построить графики спектра, eigengaps, гистограмму собственных чисел
4. **Bootstrap**: оценить стабильность результатов при повторной кластеризации
